# Common Ground

**Judgement-free. Shared stories. Practical tools. Equal ground.**

Common Ground — Mental Health Charity | Established September 25th 2026

A warm, accessible multi-page website for a UK mental health peer-support platform, podcast, and upcoming charity.

## Live site

Enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root), then visit:

**https://winowongo2024.github.io/common-ground/**

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, mission, roadmap preview, podcast placeholder |
| Founder's Story | `founders-story.html` | Our why, core values, full 3-year roadmap |
| Coping Toolkits | `toolkits.html` | Grounding, low-energy days, daily tools |
| Urgent Help | `urgent-help.html` | UK crisis contacts (999, 111, Samaritans, Mind) |
| Get Involved | `get-involved.html` | Share a story, newsletter, community advisory notice |

## Brand

- **Navy** `#0F2027` and **Muted Gold** `#D4AF37`
- Soft cream / off-white backgrounds for calm, accessible reading
- Interlocking CG logo in header (navy & gold)
