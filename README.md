# Common Ground

**Judgement-free. Shared stories. Practical tools. Equal ground.**

A warm, accessible multi-page website for a UK mental health peer-support platform and upcoming podcast/organisation.

## Live site

Once GitHub Pages is enabled, the site will be available at:

**https://winowongo2024.github.io/common-ground/**

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, mission, podcast placeholder |
| Coping Toolkits | `toolkits.html` | Grounding, low-energy days, daily tools |
| Urgent Help | `urgent-help.html` | UK crisis contacts (999, 111, Samaritans, Mind) |
| Contact | `contact.html` | Friendly form + toolkit email opt-in |

## Design

- Soft sage green, slate, and cream palette
- High contrast and clear focus states for accessibility
- Responsive (mobile, tablet, desktop)
- Skip link, semantic HTML, ARIA where needed

## Enable GitHub Pages

1. Go to the repository **Settings → Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Select branch **main** and folder **/ (root)**
4. Save — the site will be live in a minute or two

## Contact form

The contact form is currently a front-end demo. To receive real submissions, connect a service such as [Formspree](https://formspree.io) or Netlify Forms and update the form `action` in `contact.html`.
